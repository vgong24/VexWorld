# Testing and evidence

Run:

```bash
npm run check
npm run demo:headless
```

Test families currently represented:

```text
contract and source validation
compiler determinism/currentness
party-capacity and identity separation
resource/restoration margin
team-technique timing
practice evidence
bond resonance
World Witness boundaries
host lease and session versioning
remote intent freshness
headless simulation smoke
browser source smoke
```

Visual/browser playtest remains required for claims about feel, readability, timing satisfaction, and accessibility. The current automated suite is necessary but not sufficient.

# Reference grammar

Semantic references describe durable meaning; paths and runtime IDs describe realizations.

Examples:

```text
world.vexworld.first-grove
participant.companion.vex
lineage.vex.vex
vessel.first-grove.participant-companion-vex
controller.participant-companion-vex
action.vexworld.status.open
ability.vexworld.arc-dash
technique.vexworld.high-low
practice.vexworld.team-coordination
scenario.first-grove.rain-restoration
```

Do not rename a semantic reference merely because a label, translation, animation, file path, device, or model changes. A genuine meaning change may require a new generation or ref with explicit supersession.

# World Witness, resonance, and technique incubation

## Bond resonance

Relationship depth is represented through demonstrated, scope-specific facets:

```text
coordination
mutual assistance
shared practice
repair and recovery
creative collaboration
trusted delegation
play and exploration
```

It is not a hidden universal scalar.

## World Witness lifecycle

```text
eligible event evidence
→ pattern candidate
→ bounded interpretation
→ Technique Seed
→ optional incubation/refinement
→ scenario and balance evidence
→ optional quest/trial
→ lived demonstration
→ learned variant
→ private, group, world-revisitable, or public-blueprint disposition
```

## Authority boundary

World Witness may prepare semantic candidates. It cannot:

- assert participant intention as fact;
- use hidden affection or morality scoring;
- read private relationship memory by implication;
- install arbitrary executable code into a live realm;
- grant a learned ability without required trial/evidence;
- publish a private pair discovery automatically.

## Prototype seed

Repeated successful High/Low coordination can produce a `Twin Horizon` Technique Seed. When eligible, the First Grove reveals an optional trial gate. Completing the trial stabilizes a playable prototype technique. This is a fixed demonstrator of the lifecycle, not proof of general generative quest creation.

## Status and return

`action.vexworld.status.open` is one semantic action with keyboard, controller, touch, voice, model-tool, and accessibility projections. The visible status panel is not canonical state; it renders current state.

Future high-immersion adapters must retain an outer-runtime pause/orientation/return route independent of world fiction.
